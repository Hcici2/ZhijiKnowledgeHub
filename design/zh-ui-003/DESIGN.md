# 知己 · 桌面知识工作台 R2

基线为 a4436c1。设计对象是本地单用户工作台；首页任务是找到一条笔记并读下去。正式应用仍负责认证、数据库、附件原件与备份。本目录可以独立预览。

## 参考与取舍

| 参考中可核对的界面结构 | 知己的取舍 |
| --- | --- |
| Craft 区分标题、正文、图注、列表与页块，并提供专注模式。 | 文档标题统领正文；来源、分类与日期作为元数据。写作时按需展开模板，限制中文段落宽度；不把每段内容包装成卡片。 |
| Linear 将筛选与显示属性分开处理，分组列表以组名和计数帮助扫读，组内保留任务属性。 | 搜索与正在生效的条件留在结果附近；待办以日期和完成状态分组，优先显示标题、截止和来源。 |
| Finder 的图标模式用于识别内容，列表模式对齐文件属性，预览面板显示选中文件和元数据。 | 附件网格强调可辨认的缩略图；文件列表展示类型、大小、日期和来源；需要更多信息时再展开详情。 |

以上取材于官方说明及其界面示意。下表数字是针对知己示例内容和窗口尺寸制定的布局预算，不是对参考产品像素的测量。[Craft 文档结构](https://connect.craft.do/api-docs/documents/) · [Craft 专注模式](https://www.craft.do/s/fegziZPWTrBfn0) · [Linear 显示与分组](https://linear.app/docs/display-options) · [Finder 浏览模式](https://support.apple.com/guide/mac-help/organize-your-files-in-the-finder-mchle9f0a1b2/mac)

## 布局与排版预算

| 表面 | 设计目标 |
| --- | --- |
| 工作区 | 高度使用动态视口；桌面导航约 200px，栏目各自滚动。平板及手机收窄导航，列表与正文可分别访问。 |
| 笔记索引 | 约 352px；14–15px 标题、13px 摘要、12px 元数据。选中保留深色文字；键盘焦点另有轮廓。 |
| 阅读与写作 | 正文约 16px、行高 1.75，目标行宽 600–720px；窄屏按可用宽度收缩。标题 28–34px。引用、列表、代码、图像各有独立语义。 |
| 日历 | 完整月份和当天记录并存；当前日期与主动选中的日期有独立含义，计数表示记录的分布。 |
| 附件、任务、设置 | 文件需要并列比较，任务需要纵向扫读，设置需要按组定位；分别采用网格/列、分组行、二级导航。 |

## 视觉规范

全局令牌在 workspace.css 的 :root。默认内容纸色为白色，侧栏使用轻微偏暖的灰色；深墨色文字用于标题与选中项，深灰绿用于主操作与焦点。细线用于区分相邻面板，阴影留给浮层。系统中文字体支持离线使用。导航项与输入控件维持一致的焦点轮廓。日期组件的兼容变量引用同一组全局令牌。

## 日期组件的来源

date-entry.mjs 将正式分支已验收的 DateRangePicker.vue、NoteCalendar.vue 作为组件挂载在原型的筛选栏；date-control.js 和 date-control.css 为离线构建产物。预设和自定义提交均由原型消费，本地日期取自浏览器。安装已有前端依赖后可用 `node design/zh-ui-003/build-date.mjs` 重新构建。

## 评审方式

用长文检查真实行长、段落节奏和滚动；用日期跨度、空结果、多条文件与至少 20 项待办检查扫描效率。比较时保持视口、同一条记录和浏览任务一致；旧版没有的控件应明确标记为缺项，不换算成节省的空间。正式应用的验收与设计选择分开记录。
