# 知己工作台 · 页面与设计规范

本稿对应 main 的 6658b5d。页面盘点来自 frontend/src/App.vue 的导航、条件渲染与弹窗，以及 DateRangePicker、NoteCalendar 等组件。原型使用示例资料；下列“正式功能”用于指导后续迁移验收。

| 页面 | 正式功能与任务 | 布局决定 |
|---|---|---|
| 收集箱 | 识别待整理记录、批量归类 | 用列表扫描，选中后在阅读区判断内容与归属 |
| 我的知识库、置顶、网站与工具 | 检索、分类、排序、打开全文；置顶偏重复访问，网站偏打开链接 | 共用列表骨架；正文与链接是不同的主操作 |
| 笔记详情 | 正文、编辑、复制、版本、关联知识和待办 | 标题与日期相邻，正文单列；关联关系放在正文之后 |
| 日历 | 年月跳转、今天、每日计数、当天记录、每日回顾 | 完整月份与当天列表分区。日期格保留数量，把标题放入当天记录 |
| 附件库 | 类型、上传日期、来源、未关联筛选、预览 | 图片视频以缩略图识别；文件清单以文件名、类型及来源对齐 |
| 待办 | 状态、关键词、截止日期、批量移动和未安排任务 | 状态决定分组；截止日和关联笔记靠近任务名称 |
| 设置 | 数据概览、分类、列表显示、导入、附件目录、备份、回收站策略 | 用二级导航拆开日常偏好与数据管理；确认动作紧邻受影响的设置 |
| 回收站 | 笔记与附件、恢复、批量永久删除 | 两种对象明确分流；恢复为常用操作，永久删除单独确认 |
| 新建、编辑 | 标题、富文本、模板、分类、日期、附件、草稿保护 | 写作区为主，模板及低频工具按需展开，保存始终可见 |
| 登录与账户 | 初设密码、登录、退出与修改密码 | 延续现有流程；原型直接进入示例工作区 |

## 视觉和交互规范

- 信息层级依次为文档标题、段落小标题、正文、辅助元数据。中文使用本机无衬线字体。阅读正文目标 16–18 px、行高 1.7–1.8，行宽控制在约 35–43 个汉字；导航与列表标题更紧凑。
- 主导航、结果列表及文档通过共用对齐线和细分隔区分。工具栏的搜索、分类和排序靠近结果，日期和较少使用的条件按需展开。写作及阅读页留出大于列表的段落间距。
- 以中性纸白和浅灰形成背景层，强调色仅用于主操作、选中及焦点。图标使用一致的线宽与视框，图标按钮提供名称；键盘焦点、悬停、选中、禁用应可分辨。
- 四级间距以 4、8、16、32 px 为参照，分别服务于图文、控件、组内区块和页面大区。正文按内容自然增长，列表与阅读区独立浏览。
- 窄屏优先完成单一任务。阅读与列表可以分步；日历与当天记录可上下排列；设置组保持可到达；编辑器优先给正文和保存操作留空间。
- 对照时采用相同视口、缩放和示例任务，分别记录工具占高、首屏完整记录数、正文实际宽度。以浏览器测得的数值判断取舍，长文与空列表单独检查。

## 迁移验收边界

日期选择继续沿用已应用值与暂选值分离的语义；跨页筛选、返回列表的焦点与位置、草稿保护及移动工具栏需重新跑现有回归。正式数据写入、导出、迁移、永久删除和认证继续由正式应用承担。
