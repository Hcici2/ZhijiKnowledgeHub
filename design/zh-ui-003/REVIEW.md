# ZH-UI-003-R2 · 功能保留与视觉复核

## 两轮差异

R1 在详情打开时改变内容栏数，单栏笔记会跨越可用空间。R2 的桌面列表和文章始终有各自的边界：导航 200px、列表默认 350px，可拖动或用分隔条方向键调整至 300–450px。读完关闭详情时保留列表栏宽。正文 16px、行高 28px、最大行宽 670px，文档标题 28–34px。选中项采用深色文字和浅色底，按钮有独立键盘焦点。

R1 的日历与记录聚集在上半页、附件用四块相似的图形、任务只有完成和未完成两列。R2 把完整月历与当天记录并置，文件切换网格和带属性的列表，24 条待办依据截止日期和状态分成五组。设置使用二级导航，编辑器占用主工作区，保存按钮位于页首。

## 截图口径与检查边界

对照对象是原型 R1 提交 a4436c1 和 R2。两端使用相同视口、DPR 2、上海时区和固定日期。对照脚本复制笔记、附件名称、任务和完成状态，在编辑页填写相同草稿。R1 的阅读页原本只能显示硬编码的短正文，拍摄时将对应的长文置入原有正文元素。R1 的日历计数、集合归属、设置分组和回收站空状态存在硬编码，两版这些区域只作布局与功能差异观察，不能据此计算性能或效率增益。

实际运行了 12 个页面或状态：两轮在 1440×900 及 1280×800 对照；R2 另覆盖 768×1024 和 390×844。72 次页面记录中未发现 document 水平溢出或未捕获页面异常。56 张 PNG 可在 evidence-r2 中查看。页面未横向溢出不能证明所有弹层、所有设备均无裁剪。

Impeccable 4.9.2 的 context 已运行，结合 critique、layout、typeset、polish 指南检查了基线、留白、选中色、栏宽及正文层级。对本机默认页面运行 detect，输出为空数组，见 detect.json；未逐页面执行检测器、未安装 CDP 可视叠层。已人工查看桌面合成图。浏览器操作回归覆盖真实日期组件、空搜索、当天新建、放弃草稿提示、笔记保存、视频播放、任务编辑撤销和设置开关。未实测 Safari、Firefox、读屏器、实体触屏及重启后的文件操作。本材料用于再次评审。
